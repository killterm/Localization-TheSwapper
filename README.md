# The Swapper 한국어 패치

- 게임 데이터의 저작권은 모두 제작사(Facepalm Games)에 있습니다.
  - 이 패치는 제작사의 요청에 의해 언제든 삭제될 수 있습니다.
- [기존 한글 패치](https://blog.naver.com/hahakickkick/222141557083)에서 최근 업데이트 대응 패치만 했습니다. 번역은 동일합니다.

- [스팀 상점 페이지](https://store.steampowered.com/app/231160/)

## 사용법

1. [최신 Release](https://github.com/killterm/Localization-TheSwapper/releases/latest)를 다운로드
2. 압축을 풀고 `TrueEngine.dll`과 `data` 폴더를 게임 설치 경로(`TheSwapper.exe`가 있는 폴더)에 덮어쓰기

### 제거

1. 게임 폴더의 `TrueEngine.dll` 삭제
2. 스팀 라이브러리 > The Swapper 우클릭 > 속성 > 설치된 파일 > 게임 파일 무결성 검사

_게임이 업데이트되면 실행이 안 되거나 글자가 깨질 수 있습니다. 위 방법으로 제거한 뒤 새 버전 패치를 기다려 주세요._
